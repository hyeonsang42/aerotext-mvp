# AeroText (MVP 1차) 배포본

항공 준사고 보고서 구조화 분석 시스템. 2026-2학기 항공빅데이터개론 바이브코딩 프로젝트.
김현상 (2025210508, 경상국립대학교 대학원 기술경영학과)

이 저장소는 **빌드 결과물만** 담은 배포용이다. 소스와 문서는 수업 저장소에 있다.

- 사이트: https://hyeonsang42.github.io/aerotext-mvp/
- 생성 방법: `NEXT_PUBLIC_BASE_PATH=/aerotext-mvp npm run build` 결과인 `out/` 폴더
- 서버도 데이터베이스도 API 키도 없는 정적 사이트다

원자료는 NASA ASRS Database Report Sets 이며, 제공 기관이 비식별 처리한 공개 자료다.
